This folder contains a conservative subset of Star Citizen-adjacent icons that have an explicit license on Star Citizen Wiki.

Scope
- These files were downloaded from Star Citizen Wiki / starcitizen.tools.
- They are not treated as "game-extracted assets" here.
- Only files with an explicit Creative Commons license were copied.

Folders
- `cc-by-3.0/`: Creative Commons Attribution 3.0 Unported
- `cc-by-sa-3.0/`: Creative Commons Attribution-ShareAlike 3.0 Unported

Usage notes
- Keep attribution. See `manifest.json`.
- Review the source page before reuse if you modify or redistribute a file.
- Some source pages mention additional RSI restrictions when a file contains Star Citizen intellectual property.
- For `cc-by-sa-3.0/`, preserve the ShareAlike obligations if you adapt the file.

Recommended site attribution
- Source: Star Citizen Wiki ([starcitizen.tools](https://starcitizen.tools))
- Credit the file page and license listed in `manifest.json`

Do not assume
- that these files are official RSI Fan Kit assets
- that community packs without an explicit open license are allowed here
- that game-extracted assets are safe to ship
